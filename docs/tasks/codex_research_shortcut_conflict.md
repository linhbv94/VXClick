## 1. Yêu cầu Nhiệm vụ
User đang cân nhắc chọn bộ phím tắt duy nhất cho ứng dụng macro recorder VXClick (dùng cho cả Mac và Win: Cmd = Ctrl, Opt = Alt):
- Cặp phím số:
  - **Rec:** `Cmd + Option + 1` (Mac) ⟷ `Ctrl + Alt + 1` (Windows)
  - **Play:** `Cmd + Option + 2` (Mac) ⟷ `Ctrl + Alt + 2` (Windows)

Yêu cầu Codex CLI tiến hành nghiên cứu độc lập (tra cứu tài liệu, kiến thức hệ thống macOS / Windows, và các phần mềm văn phòng / đồ họa / lập trình phổ biến):
1. **`Cmd + Option + 1` và `Ctrl + Alt + 1`** đang bị trùng với những phần mềm, công cụ, hoặc tính năng hệ thống nào trên macOS và Windows?
2. **`Cmd + Option + 2` và `Ctrl + Alt + 2`** đang bị trùng với những phần mềm, công cụ, hoặc tính năng hệ thống nào trên macOS và Windows?
3. Mức độ xung đột thực tế khi một macro recorder sử dụng tổ hợp này làm Global Hotkey (đặc biệt đối với dân văn phòng, lập trình viên, designer).
4. Nhận xét và đánh giá độc lập: Có nên dùng cặp `1 / 2` này không, hay có giải pháp nào tối ưu hơn?
